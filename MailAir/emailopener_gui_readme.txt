Email mappafigyelo - HTA GUI v4

Inditas:
1. Csomagold ki a ZIP tartalmat egy tetszoleges mappaba.
2. Inditsd el: emailopener_gui.hta
3. Valaszd ki a figyelendo mappat.
4. Kattints: Figyeles inditasa.

Funkciok:
- .eml es .msg fajlok figyelese egy kivalasztott mappaban.
- Feldolgozott fajlok athelyezese a processed almappaba.
- Windows automatikus inditas kapcsolo.
- Rejtett batch futtatas, lathato CMD ablak nelkul.
- Ikon tamogatas: emailopener.ico.

Fontos:
- A tray/minimalizalas funkcio ki lett veve.
- Bezaraskor a figyeles leall.
- A GUI HTA alapu, ezert Windows alatt fut.
